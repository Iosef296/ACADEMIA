Plataforma educativa de matemáticas · 11 módulos · 45 historias

1. Autenticación
Registro e inicio de sesión en la plataforma
Historia de Usuario 001
Como
ESTUDIANTE
Quiero
crear una cuenta con mi nombre, correo y contraseña
Para
acceder a la plataforma
Criterios de Aceptación
El formulario pide nombre, correo y contraseña.
Si el correo ya está registrado se muestra un aviso de error.
Al registrarse exitosamente el sistema inicia sesión automáticamente.
Historia de Usuario 002
Como
ESTUDIANTE
Quiero
iniciar sesión con mi correo y contraseña
Para
entrar a mi cuenta
Criterios de Aceptación
Si los datos son correctos el sistema redirige al dashboard.
Si son incorrectos se muestra el mensaje "Credenciales inválidas".
La sesión se mantiene aunque se cierre y reabra el navegador.
Historia de Usuario 003
Como
ESTUDIANTE
Quiero
que mi sesión se renueve automáticamente
Para
no tener que iniciar sesión cada poco tiempo
Criterios de Aceptación
La sesión se renueva de forma transparente mientras el usuario esté activo.
Solo se cierra si el usuario lo solicita o lleva 7 días inactivo.
El usuario no nota ninguna interrupción durante la renovación.
2. Usuarios
Perfiles, roles y estadísticas personales
Historia de Usuario 004
Como
ESTUDIANTE
Quiero
ver y editar mi perfil
Para
mantener mis datos actualizados
Criterios de Aceptación
El perfil muestra nombre, correo y foto de perfil.
Se puede cambiar el nombre y la foto.
Los cambios se reflejan en toda la plataforma al guardar.
Historia de Usuario 005
Como
ADMINISTRADOR
Quiero
asignar roles a los usuarios
Para
controlar qué puede hacer cada persona en la plataforma
Criterios de Aceptación
Los roles disponibles son: estudiante, profesor y administrador.
Solo un administrador puede cambiar el rol de otro usuario.
El usuario afectado verá sus nuevas opciones la próxima vez que ingrese.
Historia de Usuario 006
Como
ESTUDIANTE
Quiero
ver mis estadísticas de aprendizaje en mi perfil
Para
conocer mi historial de progreso de un vistazo
Criterios de Aceptación
El perfil muestra puntos acumulados, racha actual y temas trabajados.
Las estadísticas se actualizan automáticamente tras cada actividad.
Se puede ver el historial de ejercicios y exámenes realizados.
3. Temas y Ejercicios
Contenido del curso, resolución, editor de fórmulas, pasos de solución y gráficos
Historia de Usuario 007
Como
ESTUDIANTE
Quiero
ver todos los temas organizados por nivel
Para
entender cuál es mi ruta de aprendizaje
Criterios de Aceptación
Los temas se muestran en árbol jerárquico (general → específico).
Cada tema indica si está disponible o bloqueado.
Se pueden expandir los subtemas de cada sección.
Historia de Usuario 008
Como
ESTUDIANTE
Quiero
desbloquear temas nuevos al completar los anteriores
Para
avanzar de forma ordenada en mi aprendizaje
Criterios de Aceptación
Un tema bloqueado muestra qué temas previos hay que completar.
Al completar un tema los siguientes se habilitan automáticamente.
El cambio se refleja de inmediato en el árbol de temas.
Historia de Usuario 009
Como
PROFESOR
Quiero
crear temas y definir cuáles son sus prerequisitos
Para
estructurar el contenido del curso
Criterios de Aceptación
Se puede crear un tema con título, descripción y nivel.
Se puede indicar qué otros temas deben completarse antes.
Solo profesores y administradores pueden crear o editar temas.
Historia de Usuario 010
Como
ESTUDIANTE
Quiero
resolver ejercicios matemáticos paso a paso
Para
aprender el proceso completo de solución
Criterios de Aceptación
El ejercicio muestra el enunciado con fórmulas legibles.
Los pasos se revelan uno a uno con pistas opcionales.
Al completarlo puedo indicar si fue fácil, adecuado o difícil.
Historia de Usuario 011
Como
ESTUDIANTE
Quiero
indicar qué tan difícil me pareció un ejercicio
Para
ayudar a mejorar el nivel del contenido
Criterios de Aceptación
La valoración aparece al terminar el ejercicio.
Las opciones son: fácil, adecuado, difícil.
Solo se puede valorar una vez por ejercicio.
Historia de Usuario 012
Como
PROFESOR
Quiero
escribir fórmulas matemáticas y verlas renderizadas al instante
Para
crear enunciados con notación matemática correcta
Criterios de Aceptación
Las fórmulas se muestran en tiempo real con notación matemática estándar.
Soporta fracciones, integrales, matrices y símbolos comunes.
El contenido puede guardarse como ejercicio o paso de solución.
Historia de Usuario 013
Como
PROFESOR
Quiero
agregar, editar y ordenar los pasos de solución
Para
guiar al estudiante durante la resolución
Criterios de Aceptación
Cada paso puede tener una pista y una advertencia opcionales.
Los pasos se pueden reordenar arrastrando.
Los cambios se guardan individualmente por paso.
Historia de Usuario 014
Como
PROFESOR
Quiero
crear ejercicios que generen variantes con números distintos
Para
que cada estudiante reciba una versión diferente del mismo problema
Criterios de Aceptación
Puedo definir qué valores varían y en qué rango.
El sistema genera automáticamente valores distintos para cada estudiante.
El enunciado se actualiza con los valores generados al mostrarse.
Historia de Usuario 015
Como
PROFESOR
Quiero
crear gráficos matemáticos desde el editor
Para
ilustrar los conceptos del ejercicio de forma visual
Criterios de Aceptación
El editor soporta gráficos de funciones, vectores y figuras geométricas.
Se muestra vista previa del gráfico mientras se edita.
El gráfico generado se adjunta al ejercicio correspondiente.
Historia de Usuario 016
Como
PROFESOR
Quiero
que el sistema sugiera qué tipo de gráfico necesita el ejercicio
Para
no tener que configurarlo manualmente cada vez
Criterios de Aceptación
El sistema analiza el contenido del ejercicio y sugiere el tipo de gráfico.
Los tipos reconocidos incluyen: función, vector y geometría.
Puedo aceptar la sugerencia o cambiarla manualmente.
Historia de Usuario 017
Como
PROFESOR
Quiero
guardar gráficos y reutilizarlos en otros ejercicios
Para
no tener que crear el mismo gráfico más de una vez
Criterios de Aceptación
Los gráficos creados se guardan en una biblioteca personal.
Se pueden buscar y adjuntar a cualquier ejercicio o examen.
Se puede editar un gráfico sin afectar los ejercicios que ya lo usan.

Como
PROFESOR
Quiero
generar un documento PDF de un examen o guía
Para
entregarlo impreso a los estudiantes
Criterios de Aceptación
El PDF incluye encabezado, enunciados con fórmulas y espacio para respuestas.
Las fórmulas matemáticas se ven correctamente al imprimir.
El archivo se descarga con un clic.
Historia de Usuario 019
Como
PROFESOR
Quiero
armar el PDF eligiendo ejercicios y plantilla
Para
personalizar el formato del documento según la ocasión
Criterios de Aceptación
Puedo seleccionar y ordenar los ejercicios que incluirá el documento.
Las plantillas disponibles son: examen, tarea y guía de práctica.
Hay vista previa antes de descargar el archivo final.
Historia de Usuario 020

ESTUDIANTE

subir una foto de un ejercicio escrito a mano
Para
que el sistema lo digitalice automáticamente
Criterios de Aceptación
Se aceptan fotos en formato JPG y PNG.
El sistema extrae el texto de la imagen en menos de 10 segundos.
Si el reconocimiento falla, el sistema lo intenta por otra vía automáticamente.
Historia de Usuario 021
Como
PROFESOR
Quiero
digitalizar enunciados escritos en papel
Para
cargarlos rápidamente como ejercicios en la plataforma
Criterios de Aceptación
El texto extraído se puede revisar y corregir antes de guardar.
El contenido detectado se puede insertar directamente en el editor de fórmulas.
El proceso devuelve el resultado en menos de 10 segundos.
5. Exámenes
Evaluaciones en línea con resultados automáticos
Historia de Usuario 022
Como
PROFESOR
Quiero
crear exámenes donde cada estudiante reciba preguntas con números distintos
Para
evitar que los estudiantes copien entre sí
Criterios de Aceptación
Se pueden incluir preguntas con variantes numéricas automáticas.
Cada estudiante ve valores diferentes en el mismo enunciado.
Solo profesores y administradores pueden crear exámenes.
Historia de Usuario 023
Como
ESTUDIANTE
Quiero
que las preguntas del examen se ajusten a mi nivel
Para
que no sea ni demasiado fácil ni demasiado difícil
Criterios de Aceptación
Las preguntas se eligen según mi historial de respuestas previas.
Si respondo bien, las siguientes son más difíciles, y viceversa.
El examen queda registrado en mi historial de evaluaciones.
Historia de Usuario 024
Como
ESTUDIANTE
Quiero
ver el tiempo restante durante el examen
Para
organizar bien mi tiempo de respuesta
Criterios de Aceptación
El cronómetro es visible en todo momento durante el examen.
Se muestra una advertencia cuando queden 5 minutos.
Al agotarse el tiempo, el examen se envía automáticamente.
Historia de Usuario 025
Como
ESTUDIANTE
Quiero
enviar mis respuestas al terminar el examen
Para
obtener mi calificación de inmediato
Criterios de Aceptación
El botón de envío pide confirmación antes de finalizar.
El puntaje se muestra al instante tras el envío.
No se pueden modificar las respuestas una vez enviadas.
Historia de Usuario 026
Como
ESTUDIANTE
Quiero
ver el detalle de mis respuestas correctas e incorrectas
Para
saber en qué temas debo mejorar
Criterios de Aceptación
Se muestra cada pregunta con mi respuesta y la correcta.
Se indica a qué tema pertenece cada pregunta fallada.
Se muestra el puntaje total, número de correctas e incorrectas.

Historia de Usuario 028

ESTUDIANTE

responder las preguntas de otros compañeros
Para
colaborar y compartir lo que sé
Criterios de Aceptación

El autor de la pregunta puede marcar una respuesta como la correcta.
Las respuestas aparecen en orden cronológico bajo la pregunta.
Historia de Usuario 029
Como
ESTUDIANTE
Quiero
adjuntar imágenes o fotos a mis publicaciones
Para
mostrar visualmente mi duda o solución
Criterios de Aceptación
Se aceptan imágenes JPG y PNG, y documentos PDF.

8. Progreso y Rutinas
Seguimiento de avance, rachas, errores y plan de estudio personalizado
Historia de Usuario 032
Como
ESTUDIANTE
Quiero
ver mis puntos acumulados y mi nivel actual
Para
saber cuánto he avanzado en la plataforma
Criterios de Aceptación
Los puntos aumentan al completar ejercicios, exámenes y desafíos.
El nivel sube automáticamente al acumular suficientes puntos.
Se muestra una barra de avance hacia el siguiente nivel.
Historia de Usuario 033
Como
ESTUDIANTE
Quiero
ver cuántos días seguidos llevo estudiando
Para
motivarme a mantener el hábito de estudio diario
Criterios de Aceptación
La racha sube al completar al menos una actividad por día.
Si no se estudia un día, la racha vuelve a cero.
Se muestra la racha actual y la racha más larga alcanzada.
Historia de Usuario 034
Como
ESTUDIANTE
Quiero
ver en qué temas cometo más errores
Para
saber dónde debo reforzar mi aprendizaje
Criterios de Aceptación
Los errores se registran automáticamente al fallar preguntas o ejercicios.
Se muestran los temas con más errores de mayor a menor.
Se sugieren ejercicios para practicar los temas más fallados.
Historia de Usuario 035
Como
ESTUDIANTE
Quiero
indicar cómo me siento al empezar a estudiar
Para
que la plataforma adapte la sesión a mi estado del día
Criterios de Aceptación
La pregunta aparece una vez al día al ingresar a la plataforma.
Las opciones son: excelente, bien, regular, cansado, estresado.
Según la respuesta, la rutina del día ajusta su dificultad y duración.
Historia de Usuario 036
Como
ESTUDIANTE
Quiero
recibir un plan de estudio diario personalizado
Para
saber exactamente qué practicar cada día
Criterios de Aceptación
El plan considera mi estado de ánimo, mis puntos y mis errores frecuentes.
Incluye una secuencia de actividades con tiempo estimado por cada una.
La duración total se adapta al tiempo que tengo disponible.
Historia de Usuario 037
Como
ESTUDIANTE
Quiero
recibir mini lecciones enfocadas en mis puntos débiles
Para
mejorar en los temas donde tengo más dificultades
Criterios de Aceptación
Las mini lecciones se basan en los temas donde más me equivoco.
Cada una tiene duración estimada y un objetivo claro.
Se marca como completada al terminar la actividad correspondiente.

Como
ESTUDIANTE
Quiero
ganar insignias por los logros que alcance
Para
sentirme reconocido por mi esfuerzo
Criterios de Aceptación
Las insignias se otorgan automáticamente al cumplir las condiciones.
Ejemplos: "7 días seguidos estudiando", "10 ejercicios completados".
Las insignias ganadas se muestran en mi perfil.
Historia de Usuario 039

ESTUDIANTE

participar en desafíos semanales
Para

Criterios de Aceptación

Al completarlo se reciben puntos adicionales.
Se puede ver el ranking de participantes del desafío activo.
Historia de Usuario 040
Como
ESTUDIANTE
Quiero
canjear mis puntos por recompensas
Para
obtener beneficios dentro de la plataforma
Criterios de Aceptación
Cada recompensa muestra claramente cuántos puntos cuesta.
Al canjear, los puntos se descuentan de mi saldo.
Puedo ver el historial de recompensas que he canjeado.
Historia de Usuario 041
Como
ESTUDIANTE
Quiero
personalizar mi avatar
Para
tener una identidad visual propia en la plataforma
Criterios de Aceptación
Puedo elegir accesorios y elementos que haya desbloqueado.
Algunos elementos se obtienen al ganar insignias o canjear recompensas.
El avatar aparece en el perfil, el ranking y el foro.

Criterios de Aceptación

11. Administración
Panel de control para administradores de la plataforma
Historia de Usuario 044
Como
ADMINISTRADOR
Quiero
buscar y gestionar a todos los usuarios registrados
Para
mantener el control de quién accede a la plataforma
Criterios de Aceptación
Se puede buscar usuarios por nombre, correo o rol.
Se puede activar, desactivar o cambiar el rol de cualquier usuario.
Solo administradores tienen acceso a este panel.
Historia de Usuario 045
Como
ADMINISTRADOR
Quiero
gestionar el árbol completo de temas matemáticos
Para
mantener el contenido académico organizado y actualizado
Criterios de Aceptación
Se pueden crear, editar y eliminar temas desde el panel.
Al eliminar un tema con ejercicios o subtemas asociados se muestra una advertencia.
Los cambios se reflejan de inmediato para todos los usuarios.
